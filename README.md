# Tanner-graph cycle counting — reproducibility materials

Code, graph definitions, realized edge lists, validation records, and timing data for the exact-versus-Karimi–Banihashemi comparison and the single-processor interleaved hybrid in the October 11 manuscript.

## Manuscript tables and current hybrid

- [Table 1 data](paper_table1_exact_20261011.csv) preserves the graph rows, counts, and reported timings in the manuscript.
- [Table 2 data](paper_table2_hybrid_20261011.csv) is rounded to two decimals from the archived Q=4096 measurements in [measurements_optimized.csv](measurements_optimized.csv).
- `interleaved_optimized.cpp`, `run_optimized.py`, and `run_exact_table.py` provide the current implementation and rerun procedures.
- `EXPERIMENT_optimized.md` documents the settings and how the table snapshots relate to the data.

The hybrid configuration is `epsilon=0.08`, `r=101`, `Q=4096`, with 100 repetitions. The archived CSV stores the aggregate measurements; the table snapshot rounds its KB time, recursive exact time, hybrid time, and MARE. Fresh timings depend on machine and load, and fresh sampling outcomes can vary by seed. The exact table snapshot preserves the manuscript's reported values; the runner writes fresh seven-run medians.

## Graphs and verification

- `generate.py`, `generate_diverse.py`, `generate_qc.py`, and `manifest*.json` define graph families, parameters, and QC instances. Q410 and Q412 are generated by `generate_qc.py`; `manifest_qc.json` records their parameters, expected counts, and hashes.
- `graphs/` contains manuscript benchmark instances and correctness-test graphs. The Q410/Q412 edge lists are generated locally by `generate_qc.py`.
- `verify.py`, `verify_diverse.py`, `verification.json`, and `verification_diverse.json` record degree, simplicity, connectivity, girth, and additional correctness checks.
- `QC_BENCHMARKS.md` documents the Q410/Q412 construction.

To regenerate the QC graphs and produce fresh timing records, run from the repository root:

```sh
python3 generate_qc.py
python3 run_exact_table.py
python3 run_optimized.py
```

Fresh timings are machine- and load-dependent. Do not compile checking programs with `-DNDEBUG`, because some validation assertions also execute checks.

All graphs are synthetic Tanner-graph instances, not standardized LDPC codes.
